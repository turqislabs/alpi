# Security

Please **don't** report security problems as public issues.

Send an email to **musa.oezdil@icloud.com** with the subject “Alpi security” and, if possible,
steps to reproduce and your Alpi and macOS version (Alpi menu › Feedback geben › Systemangaben kopieren).
You'll get an answer within a few days.

---
