# Changelog

## 0.7 Beta – first public beta

The first public version of Alpi. Free while it's in beta.

- Capture: area, window, full screen, scrolling capture (with auto-scroll), text from an area, self-timer
- Screen recording to MP4 or GIF with clicks, microphone, system audio and camera bubble
- Editor: annotations, redaction (auto-detects personal data and faces), frames, adjustments, history
- Orbit: screenshot cards, smart actions (text, QR, dates, tables), shelf, pinning
- Clipboard history, colour picker, QR codes, drawing on screen
- File conversion by drag & drop, including Office documents
- Ask Alpi, with Apple Intelligence on macOS 26/27 (image understanding on macOS 27)
- Folder rules and Shortcuts actions
- Privacy & security settings: history retention, clipboard clearing, link checks, shortcut confirmation
- In-app feedback and update notice

*App language: German. English planned.*
